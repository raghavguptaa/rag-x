# RagX

A modern, secure encryption platform for text, file encryption, and PDF protection — built with a clean dashboard-style interface.

---

## Overview

RagX is a web-based cryptographic suite designed to provide secure and efficient encryption directly in the browser.

It combines client-side cryptography with backend-powered processing to deliver a seamless and secure experience.

With RagX, users can:

- Encrypt and decrypt text securely  
- Encrypt files with downloadable key packages  
- Lock and unlock PDF documents using passwords  
- Manage encryption keys safely and efficiently  

---

## Core Features

### Text Cipher
Encrypt and decrypt messages using AES-256-GCM, ensuring confidentiality and integrity.

---

### File Cipher
Encrypt files directly in the browser and download a structured key and IV package for secure future access.

---

### PDF Protection
Apply password-based protection to PDF files. Only authorized users can unlock and access the content.
