Features

Everything you need to protect data

Six focused tools, one clean interface.

01

Text Cipher

Encrypt messages with AES-256-GCM. A fresh key and IV are generated for every message, entirely in your browser.

02

File Cipher

Encrypt any file locally and download a key package for later decryption. Nothing is uploaded.

03

Password Vault

Protect text or files with a single password. The key comes from PBKDF2 and even the original file name is encrypted.

04

PDF Protection

Lock and unlock PDFs with AES-256 password protection, with size limits and rate limiting on the server.

05

Password Generator

Create strong passwords using the browser's secure random generator, with a live entropy meter.

06

Hash Checker

Fingerprint text or files with SHA-256 and compare against a published hash to detect tampering.

How it works

Three steps, no accounts

1

Choose a tool

Pick text, file, vault or PDF protection. No account needed to use the tools.

2

3

Never stored anywhere: your messages, files, keys and vault passwords.

Is my data uploaded anywhere?

Text, File and Vault encryption run entirely in your browser. Only PDF lock and unlock sends the file and password to the server, where it is processed in memory and not saved.

What if I forget my vault password?

It cannot be recovered. No key or password is stored anywhere, which is exactly what keeps your data safe.

Which algorithms are used?

AES-256-GCM for encryption, PBKDF2-HMAC-SHA256 for password-based keys, SHA-256 for hashing and AES-256 for PDF protection.

Can I use Rag X without an account?

Yes. All six tools work without signing in. An account only adds a personal dashboard.

What files can I encrypt?

File Cipher and the Password Vault accept any file type, limited only by your browser's memory. PDF Protection accepts PDFs up to 20 MB.

Is it safe for highly sensitive data?

Rag X is a learning and portfolio project built on standard, well-reviewed cryptography. For critical secrets, use professionally audited tools.
