What it does

Everything in the toolkit

Six tools grouped into four areas.

01

Text and File Cipher

AES-256-GCM encryption in your browser, with a fresh key and IV for every operation.

02

Password Vault

Protect text or files with one password. Keys come from PBKDF2 and file names are encrypted too.

03

PDF Protection

Lock and unlock PDFs with AES-256 password protection, processed in memory and never saved.

04

Security Tools

A secure password generator with an entropy meter, and a SHA-256 hash checker for file integrity.

Security design

Built so there is little to steal

Sensitive work happens on your device. The server only handles what it has to, and keeps almost nothing.

  • AES-256-GCM with a random IV for every operation
  • PBKDF2-HMAC-SHA256 with 600,000 iterations
  • Authenticated file headers, so tampering is detected
  • Strict Content Security Policy, rate limiting and upload limits
  • Accounts store only an email and a hashed password
